Integrasi Pengiriman Email

EmailJS untuk pengiriman struk otomatis langsung dari browser

Gratis & Tanpa Server Backend:

Layanan EmailJS.com memberikan 200 email/bulan secara gratis. Anda cukup menghubungkan akun Gmail/SMTP di EmailJS dan menyalin 3 kunci di bawah.

*Jika kunci belum diisi, sistem menampilkan peringatan dan tidak akan mengirim atau mengunduh struk secara otomatis. Isi kunci EmailJS untuk pengiriman langsung.

Format Template EmailJS:

Template ini otomatis memuat Kode QR Gambar Asli (menggunakan parameter {{qr_code_url}}) sehingga peserta langsung melihat QR code di email mereka!
